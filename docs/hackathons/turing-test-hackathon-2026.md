# The Turing Test Hackathon 2026

## Overview

The Turing Test Hackathon 2026 is a two-phase AI hackathon organized by Mantle and co-hosted with Bybit, Byreal, and Blockchain for Good Alliance (BGA), with support from DoraHacks and HackQuest.

It focuses on agentic AI, on-chain infrastructure, and verifiable execution on Mantle. The core idea is to benchmark autonomous agents in a real on-chain environment where key decisions and outcomes are recorded permanently.

## Core Facts

- Total prize pool: `$120,000`
- Format: `online / virtual`
- Registration deadline: `June 15, 2026`
- Demo Day: `July 2-3, 2026`
- Main chain: `Mantle`
- Primary theme: `AI agents + on-chain execution + verifiable outcomes`

### 20 Project Deployment Award

This award goes to the first 20 projects that satisfy the deployment requirements.

## Three Defining Features

1. On-chain benchmarking of AI
   - Every agent decision and outcome is recorded on Mantle.
   - This creates an auditable record of performance.

2. ERC-8004 agent identity
   - Each participating agent receives a unique identity NFT.
   - This creates an on-chain identity and reputation trail.

3. Radical transparency
   - AI Awakening will be live-streamed globally.
   - The public can observe execution, adaptation, and self-correction in real time.

## Practical Implications for Building

If we enter, the project should likely satisfy these properties:

- Real on-chain actions, not just a demo UI
- Clear AI role in execution or decision-making
- Strong Mantle-specific integration
- A visible, polished frontend
- A verifiable submission story that judges can inspect quickly
