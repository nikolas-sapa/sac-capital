# Situational Awareness Calibration Check (2026)

Leopold Aschenbrenner's "Situational Awareness" (June 2024) is the source essay behind the AI-compute structural thesis in `equities/research/thesis_miner.py`, and indirectly behind the grid-infrastructure thesis that the repo's `discovery_lag.py` leaf-supplier bets (VRT, ETN, GEV, CEG, PWR) already assume. The core mechanism `DiscoveryLagCalculator` exploits — leaf suppliers lagging the trunk stock in price discovery — only generates edge while the market is still slow to price the thesis in. If a thesis's core premise has already become consensus (i.e., it shows up in every sell-side note and is fully reflected in hyperscaler/Nvidia guidance), the "still mispriced" assumption weakens and the thesis should be down-weighted rather than treated as a fresh signal. This note checks the essay's checkable, named predictions against what has actually happened from 2024 through mid-2026, using only figures found via web search (each cited below), and translates the verdicts into a recommended `confidence_multiplier` for each of the five `STRUCTURAL_THESES` entries.

## Notes on method

- All revenue/capex figures above are taken directly from the search results returned during this session (Nvidia investor-relations press releases via nvidianews.nvidia.com and SEC 8-K filings; CNBC, Tom's Hardware, Fortune coverage of hyperscaler capex guidance; Pew Research Center; Manufacturing Dive's CHIPS tracker; DefenseScoop/Defense One/Breaking Defense Pentagon budget coverage; WEF, Deloitte, and an arXiv survey on grid constraints).
- No figure in this note was estimated, interpolated, or invented — anywhere this note could not find a directly checkable number (e.g., a single isolated "2026 GLP-1 penetration %" figure, or a tracked "% of manned platforms replaced" metric), it says so explicitly rather than guessing.
- This is a point-in-time check (research run June 2026); multipliers should be revisited as new hyperscaler earnings, CHIPS Act milestones, and Pentagon budget cycles land.
